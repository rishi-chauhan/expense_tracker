1. Goals & Non-Goals

V2 keeps the app local-first and single-user, but makes it safe and operable as an always-on service on a Raspberry Pi on a home LAN.

Goals

  • Close high-value product gaps: categories, statement management, export, budgets
  • Improve maintainability (shared API client, hooks, CI, doc fixes) without a rewrite
  • Add app-level production knobs: health checks, env config, HOST binding, upload limits
  • Deploy safely on a Raspberry Pi behind a reverse proxy with authentication
  • Protect financial data from other devices on the LAN (proxy + firewall still needed)
  • Add ops artifacts: systemd unit, backups, Caddyfile, install notes

Non-Goals (still out of scope)

  • Cloud hosting, SaaS signup, or multi-tenant accounts
  • Mobile native apps (responsive web on LAN is enough)
  • Replacing SQLite with Postgres/MySQL
  • Full TypeScript rewrite in one shot
  • Internet exposure without a carefully reviewed threat model
Constraint (unchanged): Prefer reverse-proxy auth (Caddy/nginx basic auth) over building a full in-app auth system. In-app login can come later if multi-user is needed.

2. Overview & Current State

Paisa Kidhar Gaya?! is a full-stack local-first expense analyzer built with Bun (backend), React 19 (frontend), and SQLite (storage). Users upload Indian credit card CSV statements; the backend parses, categorizes, and deduplicates transactions; the frontend provides Chart.js dashboards, statement/category management, budgets, and an optional Ollama AI chat assistant.
